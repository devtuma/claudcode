# 🚀 Como Configurar o GitHub Pages - Passo a Passo

## ⚠️ IMPORTANTE

O GitHub Pages precisa ser configurado manualmente nas configurações do seu repositório. Siga os passos abaixo:

---

## 📋 Passo a Passo Detalhado

### 1️⃣ Acesse as Configurações do Repositório

1. Vá para: **https://github.com/devtuma/claudcode**
2. Clique na aba **Settings** (⚙️ Configurações) no topo da página

### 2️⃣ Navegue até Pages

1. No menu lateral esquerdo, role até encontrar a seção **Code and automation**
2. Clique em **Pages**

### 3️⃣ Configure o Source (Origem)

Na página de GitHub Pages, procure a seção **"Build and deployment"** ou **"Source"**:

1. **Branch**: Selecione `claude/transkwanza-p2p-remittance-011CUqpNmgnVozc53stKuqJx`
   
2. **Folder**: Selecione `/docs`

3. Clique no botão **Save** (Salvar)

### 4️⃣ Aguarde o Deploy

- Após salvar, o GitHub irá automaticamente fazer o deploy
- Isso pode levar **2-5 minutos**
- Você verá uma mensagem: "Your site is published at https://devtuma.github.io/claudcode/"

### 5️⃣ Acesse Sua Demo

👉 **https://devtuma.github.io/claudcode/**

---

## 🔍 Verificar Arquivos

Confirme que estes arquivos existem em `docs/`:
- index.html
- dashboard-demo.html
- style.css
- demo.js
- README.md

---

## 📞 Ainda não funcionou?

**Causa mais comum**: GitHub Pages não está configurado no repositório.

**Solução**: Siga os passos 1-3 acima para configurar manualmente.

---

**✨ Depois de configurado, aguarde 2-3 minutos e acesse o link!**
